# Interconnect v0.5.1

This patch release improves notification keyboard navigation and read-state handling.

- Open Notifications with Ctrl+I on Linux or Cmd+I on macOS. Page Up and Page Down
  scroll the notification list even when the pointer is outside it.
- Keep notifications read when their history arrives after the source messages
  have already been viewed.
- Mark invitation notifications read after accepting or declining the invitation.
- Clarify the keyboard shortcut documentation.

See the [keyboard shortcuts](https://github.com/FreakyPenguin/interconnect/blob/v0.5.1/docs/keyboard.md)
and [current limitations](https://github.com/FreakyPenguin/interconnect/blob/v0.5.1/docs/limitations.md)
for details. Download `SHA256SUMS` alongside the packages to verify their checksums.
