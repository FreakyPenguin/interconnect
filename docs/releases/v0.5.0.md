# Interconnect v0.5.0

This release adds polls, more room moderation controls, and better tools for
technical conversations.

## Highlights

- **Polls in rooms and threads.** Create single- or multiple-choice polls with
  visible or hidden results, reorder answers, and vote in existing polls. Authors
  can end their polls or edit unanswered polls before they end. Poll creation
  drafts are saved encrypted alongside text drafts.
- **Moderation and reporting.** Ban by Matrix user ID, review banned members,
  unban, and add reasons to moderation actions. Message menus offer sender removal
  and banning when permitted. Confirmed message reports go to your homeserver
  administrators; reporting does not remove the message or ban its sender.
- **Space addresses and linking.** Manage local and published space addresses.
  Link rooms and subspaces from discovery results or an address without joining
  them. Shared parents are supported, and linking keeps the current conversation
  open.
- **Code and tables.** Long code blocks start with a bounded preview, with
  keyboard-accessible Expand, Copy, and Save controls and horizontal scrolling.
  Copy and Save include the full block. Compose Markdown tables and read received
  HTML tables as selectable, aligned grids. Set message text size independently
  of the rest of the interface.
- **Retained conversation state.** Recent conversations remember text selection,
  spoiler reveals, code expansion, and horizontal offsets during the session.
  Thread originals retain their own presentation and scroll state.
- **Platform keyboard behavior.** App shortcuts use Command on macOS and Control
  on Linux. Multiline editors and message selection share native text movement
  bindings, while dialogs, completion, and IME composition take precedence.

Message notifications are now marked read when their source message becomes
visible. List formatting also handles bullet items beginning with a date correctly.

## Requirements and limits

Interconnect remains experimental. Linux/Wayland is the primary development
platform. Apple Silicon macOS builds are best-effort, ad-hoc signed, and not
notarized.

Your homeserver must support native sliding sync. Account storage requires Linux
Secret Service or macOS Keychain; each process uses one account. Polls use the
experimental MSC3381 format. Retained selection and code presentation state are
session-only; text and poll creation drafts persist locally across restarts.

See the [keyboard shortcuts](https://github.com/FreakyPenguin/interconnect/blob/v0.5.0/docs/keyboard.md),
[message controls](https://github.com/FreakyPenguin/interconnect/blob/v0.5.0/docs/messages.md),
and [current limitations](https://github.com/FreakyPenguin/interconnect/blob/v0.5.0/docs/limitations.md)
for details. Download `SHA256SUMS` alongside the packages to verify their checksums.
