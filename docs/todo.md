# Ideas

Current gaps are listed in [limitations](limitations.md). Further work includes:

## Messaging and media

- @mention completion.
- Ordinary replies.
- Multiple attachments per send.
- Standalone stickers and animated custom emoji.
- Better GIF handling (play button without opening fully).
- Giphy integration?

## Navigation and notifications

- Clickable notifications that open the relevant conversation.
- Room notification controls.
- Unread catch-up divider.
- Conversation back/forward history (after search, following links, etc.).
- Keyboard shortcuts for jumping between spaces.
- Search with filters
- Allow matrix URIs to be (de)registered through settings

## Appearance and message display

- Dark mode.
- Text size control
- Syntax highlighting.
- Scrollable code blocks (optional in settings, preview lines configurable).
- Copy link action on URLs.

## Room and space management

- Room settings, member removal, and member invite links.
- Creating and managing spaces.
