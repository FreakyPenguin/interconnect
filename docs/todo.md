# Ideas

See [limitations](limitations.md) for existing gaps.

- Standalone stickers, animated custom emoji, possibly Giphy.
- Use the [performance fixtures](validation/long-history.md) to improve very long
  plain prose and explicitly expanded code; both still use full layout.
- Custom palettes. Independent message text sizing is already available.
- Configurable code-preview limits; bounded previews, horizontal scrollbars, and
  Copy/Save are already implemented.
- Advanced room settings (power rules, encryption, upgrades) and bans.
- Space aliases and links to unjoined children.
