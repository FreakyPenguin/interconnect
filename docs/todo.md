# Ideas

See [limitations](limitations.md) for existing gaps.

- Standalone stickers, animated custom emoji, possibly Giphy.
- Use the [long-history measurements](validation/long-history.md) to evaluate
  further rendering improvements, including very long individual messages.
- Matrix URI handler registration in Settings.
- Custom palettes and independent text-size controls.
- Optional scrollable code blocks with configurable preview lines.
- Advanced room settings (power rules, encryption, upgrades) and bans.
- Space aliases and links to unjoined children.
